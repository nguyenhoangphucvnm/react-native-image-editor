# Security Policy

## Supported Versions

Please use the table below to check if your version of `@phucprime/react-native-image-editor` is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `@phucprime/react-native-image-editor` seriously. If you discover a security vulnerability, please follow these steps:

1. **Do NOT open a public GitHub issue** to report a security vulnerability.
2. Send a detailed report describing the vulnerability directly via private disclosure on GitHub or contact the maintainer at `phucprime` on GitHub.
3. Include detailed steps to reproduce the vulnerability, including platform information (iOS/Android), React Native version, and payload examples if applicable.

---

## Disclosure Policy

- Once a vulnerability report is received, the project maintainer will acknowledge receipt within **48 hours**.
- A fix will be developed, tested, and published as a patch release (`v1.x.Y`) as soon as possible.
- Public credit will be given to the reporter after the fix is published (unless requested otherwise).
